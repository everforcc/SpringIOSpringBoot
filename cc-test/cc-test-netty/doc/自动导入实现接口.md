# 自动导入实现接口方案说明

在实际开发中，为了避免每次都手动添加 handler，可以采用自动注册所有实现了 `HttpRequestHandler` 接口的类。常见方案如下：

---

## 1. Spring自动注入（推荐，适合Spring项目）

- 所有 Handler 类加上 `@Component` 注解。
- 在主类中用 `@Autowired List<HttpRequestHandler> handlers;`，Spring会自动注入所有实现。
- 这样只需写好 Handler 类，无需手动 add。

**优点**：最优雅、最易维护，支持依赖注入。

---

## 2. 反射+包扫描（适合纯Java项目，无IOC容器时）

- 启动时扫描指定包下所有类，判断是否实现了 `HttpRequestHandler` 接口，自动实例化并加入列表。
- 推荐使用 `org.reflections` 等包扫描工具。

**示例代码：**

```java
import org.reflections.Reflections;

Reflections reflections = new Reflections("cn.cc.netty.learn.mqtt.handler.impl");
Set<Class<? extends HttpRequestHandler>> handlerClasses = reflections.getSubTypesOf(HttpRequestHandler.class);

for (Class<? extends HttpRequestHandler> clazz : handlerClasses) {
    // 假设有无参构造器
    handlers.add(clazz.getDeclaredConstructor().newInstance());
}
```
> 如果 Handler 需要依赖参数（如 publishService），可用工厂或构造参数注入。

---

## 3. SPI机制（适合插件式扩展）

- 在 `META-INF/services` 目录下注册接口实现。
- 适合做插件式扩展和解耦。

---

## 总结

- Spring项目推荐用自动注入，最简单。
- 纯Java项目可用包扫描+反射自动注册。
- 自动注册能极大提升扩展性和开发效率。

如需具体实现代码，可根据实际项目结构进一步细化。
