## 接口说明

| 字段名称                | 约束 | 字段类型 | ⻓度 | 字段描述           | 取值说明                                                     |
| :---------------------- | :--- | :------- | :--- | :----------------- | :----------------------------------------------------------- |
| org_code                | 必传 | Long     | 20   | 机构编号           | 鉴权机构                                                     |
| user_no                 | 必传 | Long     | 20   | 商户归属用户信息   | 合作机构信息 由拓客SAAS提供                                  |
| email                   | 必传 | String   | 80   | 商户邮箱           |                                                              |
| busi_code               | 必传 | String   | 20   | 业务类型           | 见附录-业务类型表，如：WECHAT_PAY                            |
| mer_reg_name            | 必传 | String   | 80   | 商户注册名称       | 与营业执照名称一致，超出20字可缩减至20字以内                 |
| mer_type                | 必传 | String   | 80   | 商户注册类型       | TP_MERCHANT:企业TP_PERSONAL:⼩微个⼈                         |
| mer_name                | 必传 | String   | 80   | 商户名称(经营名称  | 不能少于7个中文                                              |
| mer_addr                | 必传 | String   | 80   | 商户详细地址       | 去掉省，市区后的详细地址                                     |
| province_code           | 必传 | String   | 16   | 省代码             | 通过【获取地区查询】接口获取 对应 code字段                   |
| city_code               | 必传 | String   | 16   | 市代码             | 通过【获取地区查询】接口获取 对应 code字段                   |
| county_code             | 必传 | String   | 16   | 区县代码           | 通过【获取地区查询】接口获取 对应 code字段                   |
| license_name            | 可选 | String   | 80   | 营业执照名称       | 同营业执照附件名称一致                                       |
| license_no              | 可选 | String   | 40   | 营业执照号码       | ⼩微商户可不传， 其他必传                                    |
| license_dt_start        | 可选 | String   | 10   | 营业执照开始时间   | ⼩微商户可不传， 其他必传，格式yyyy-MM-dd                    |
| license_dt_end          | 可选 | String   | 10   | 营业执照过期时间   | ⼩微商户可不传， 其他必传，格式yyyy-MM-dd长期传：9999-12-31  |
| latitude                | 必传 | String   | 20   | 经度               | 进件所在地址经度                                             |
| longtude                | 必传 | String   | 20   | 纬度               | 进件所在地址纬度                                             |
| source                  | 必传 | String   | 20   | 进件来源           | APP, H5 （2选1）                                             |
| business_content        | 必传 | String   | 64   | 商户经营内容       | 营业执照上的经营内容，不可超长                               |
| is_legal_person         | 可选 | boolean  |      | 是否法⼈进件       | 不传默认法人                                                 |
| lar_name                | 必传 | String   | 20   | 法⼈姓名           |                                                              |
| lar_id_type             | 必传 | String   | 8    | 法⼈证件类型       | 01 身份证，02 护照，03 港澳通行证，04 台胞证，10 外国人永久居留身份证，11 港妨澳居民居住证，12 台湾居民居住证，13 执行事务合伙人，99 其它证件 |
| lar_id_card             | 必传 | String   | 40   | 法⼈证件号码       |                                                              |
| lar_id_card_start       | 必传 | String   | 10   | 法⼈证件开始⽇期   | 格式yyyy-MM-dd                                               |
| lar_id_card_end         | 必传 | String   | 10   | 法⼈证件过期时间   | 格式yyyy-MM-dd 长期传：9999-12-31                            |
| contact_mobile          | 必传 | String   | 20   | 商户联系⼈⼿机号码 |                                                              |
| contact_name            | 必传 | String   | 32   | 商户联系⼈姓名     |                                                              |
| openning_bank_code      | 必传 | String   | 20   | 结算账户开户⾏号   | 通过【银行列表查询】接口获取 对应 branchBankNo字段           |
| openning_bank_name      | 必传 | String   | 40   | 结算账户开户⾏名称 | 通过【银行列表查询】接口获取 对应 branchBankName字段         |
| clearing_bank_code      | 必传 | String   | 20   | 结算账户清算⾏号   | 通过【银行列表查询】接口获取 对应 clearNo字段                |
| settle_province_code    | 必传 | String   | 20   | 结算信息省份代码   | 通过【获取银行地区查询】接口获取 对应 code字段               |
| settle_province_name    | 必传 | String   | 20   | 结算信息省份名称   | 通过【获取银行地区查询】接口获取 对应 name字段               |
| settle_city_code        | 必传 | String   | 20   | 结算信息城市代码   | 通过【获取银行地区查询】接口获取 对应 code字段               |
| settle_city_name        | 必传 | String   | 20   | 结算信息城市名称   | 通过【获取银行地区查询】接口获取 对应 name字段               |
| account_no              | 必传 | String   | 40   | 结算人银行卡号     |                                                              |
| account_name            | 必传 | String   | 40   | 结算人账户名称     |                                                              |
| account_type            | 必传 | String   | 8    | 结算账户类型       | 57 对公，58 对私                                             |
| account_id_type         | 可选 | String   | 8    | 结算⼈证件类型     | 为空同法⼈                                                   |
| account_id_card         | 必传 | String   | 8    | 结算⼈证件号码     |                                                              |
| account_id_dt_start     | 可选 | String   | 8    | 结算⼈证件开始时间 | 为空同法⼈                                                   |
| account_id_dt_end       | 可选 | String   | 8    | 结算⼈证件过期时间 | 为空同法⼈                                                   |
| external_no             | 可选 | String   | 32   | 外部编号           | 外部编号                                                     |
| biz_content             | 必传 | Object   | 0    | 业务扩展信息       | 参⻅ 业务扩展信息                                            |
| attchments              | 必传 | Set      | 集合 | 附件信息集合       | 参⻅ 附件信息                                                |
| settle_type             | 必传 | String   | 10   | 结算类型           | D0秒到 D1次日结算                                            |
| shop_id                 | 可选 | String   | 20   | ⽹点代码           | ⾮连锁店不填                                                 |
| settlement_type         | 必传 | String   | 20   | 结算方式           | MANUAL:手动结算(结算至拉卡拉APP钱包),AUTOMATIC:自动结算,REGULAR:定时结算（仅企业商户支持） |
| regular_settlement_time | 可选 | int      | 20   | 定时结算时间       | 定时结算必传 格式为 HHmm 例如结算时间为下午3点 传入值为 1500 |
| contract_no             | 可选 | String   | 80   | 电子合同编号       | 电子合同接口获取，[跳转至电子合同接口文档](https://o.lakala.com/#/home/document/detail?id=289) 此编号和AGREE_MENT附件，二选一即可 |

### 业务拓展信息

| 字段名称        | 约束 | 字段类型 | ⻓度     | 字段描述                                 | 取值说明                                  |
| :-------------- | :--- | :------- | :------- | :--------------------------------------- | :---------------------------------------- |
| term_num        | 必传 | String   | 2        | 终端数量                                 | 1                                         |
| term_ver        | 可选 | String   | 80       | 终端版本                                 |                                           |
| fees            | 必传 | Set      | 费率集合 | 费率集合                                 |                                           |
| mcc             | 必传 | String   | 8        | 商户MCC编号                              | 通过 【获取小类】接口获取 对应 code字段   |
| activity_id     | 必传 | Long     | 8        | 归属活动信息                             | 由拓客SAAS分配，见附录-业务类型表本地文件 |
| withdrawal_type | 可选 | string   |          | 提款类型,可用值[SECOND:秒到;AMOUNT:秒提] |                                           |

### 费率信息

| 字段名称  | 约束 | 字段类型 | ⻓度 | 字段描述 | 取值说明             |
| :-------- | :--- | :------- | :--- | :------- | :------------------- |
| fee_code  | 必传 | String   | 20   | 费率类型 | 参考 附录-费率类型表 |
| fee_value | 必传 | Double   | 80   | 费率值   | 百分比费率           |
| top_fee   | 可选 | Double   | 80   | 封顶值   | 单位为元             |

### 附件信息

| 字段名称 | 约束 | 字段类型 | ⻓度 | 字段描述 | 取值说明                                        |
| :------- | :--- | :------- | :--- | :------- | :---------------------------------------------- |
| id       | 必传 | String   | 20   | ⽂件地址 | 通过【**商户进件文件上传**】接口获取对应url字段 |
| type     | 必传 | String   | 80   | 附件类型 | 参考 附录-附件类型表                            |
