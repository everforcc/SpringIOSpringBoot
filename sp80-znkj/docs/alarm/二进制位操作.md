# Java位操作详解文档

## 概述

本文档详细解释了Java中涉及的关键位操作代码，主要分析以下三行重要代码：
- 第44行：`b |= (1 << k);`
- 第72行：`int b = bytes[i / 8] & 0xFF;`
- 第75行：`arr[i] = (b >> (i % 8)) & 1;`

这些代码实现了一个完整的位图压缩和解压缩过程。

## 核心概念

### 位运算符
Java中的主要位运算符包括：
- `&` (按位与)
- `|` (按位或)
- `<<` (左移)
- `>>` (右移)
- `~` (按位非)

## 详细解释

### 第44行: `b |= (1 << k);`

#### 功能
设置整数[b](file://C:\cc\code\gitee\SpringIOSpringBoot\cc-test\cc-test-jdk\src\main\java\cn\cc\jdk\base\InstanceofB.java#L11-L11)的第`k`位为1（位索引从0开始）。

#### 拆解分析
1. `1 << k` - 将数字1左移k位
    - 例如：当k=3时，`1 << 3` = `1000`（二进制）
2. `b |= ...` - 使用按位或操作将对应位设置为1
    - `|=`是复合赋值运算符，等价于`b = b | (1 << k)`
    - 这种方式只会影响目标位，不会改变其他位的值

#### 应用场景
将字符串中的'1'字符转换为对应的位设置在字节中，实现位图压缩。

### 第72行: `int b = bytes[i / 8] & 0xFF;`

#### 功能
将有符号的`byte`值转换为无符号的`int`值（0-255范围）。

#### 拆解分析
1. `bytes[i / 8]` - 获取第[i](file://C:\cc\code\gitee\SpringIOSpringBoot\sp72-webmagic\src\main\java\cn\cc\kunnu\pageprocessor\KunNuPageProcessor.java#L20-L20)位所在的字节（每8位占1字节）
2. `& 0xFF` - 屏蔽高位，只保留低8位
    - `0xFF` = `11111111`（二进制）
    - 通过按位与操作，高24位全部置为0

#### 为什么要屏蔽高位？
- Java中`byte`是有符号类型，范围为-128到127
- 直接转换为`int`时会发生符号扩展
- 使用`& 0xFF`可以获取0-255的无符号值

#### 示例

~~~
java 
byte b = -1; // 二进制: 11111111 
int i = b; // 符号扩展: 11111111 11111111 11111111 11111111 
int j = b & 0xFF; // 屏蔽高位: 00000000 00000000 00000000 11111111 = 255
~~~

### 第75行: `arr[i] = (b >> (i % 8)) & 1;`

#### 功能
提取字节[b](file://C:\cc\code\gitee\SpringIOSpringBoot\cc-test\cc-test-jdk\src\main\java\cn\cc\jdk\base\InstanceofB.java#L11-L11)中第`(i % 8)`位的值（0或1）。

#### 拆解分析
1. `i % 8` - 计算在当前字节中的位索引（0-7）
2. `b >> (i % 8)` - 将目标位右移到最低位
3. `& 1` - 提取最低位的值
    - `1` = `00000001`（二进制）
    - 通过按位与操作，只保留最低位

#### 示例
假设`b = 170`（二进制: `10101010`）：
- 提取第0位：`(170 >> 0) & 1` = `10101010 & 1` = `0`
- 提取第1位：`(170 >> 1) & 1` = `01010101 & 1` = `1`
- 提取第2位：`(170 >> 2) & 1` = `00101010 & 1` = `0`
